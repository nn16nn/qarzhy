# Qarzhy

Жеке қаржы қосымшасы (PWA): кіріс-шығын, шоттар, несие, мақсаттар, қарыздар, тұрақты төлемдер, есептегіштер, банк үзіндісін жүктеу.

https://nn16nn.github.io/qarzhy/

- `index.html` — құрылым және стиль
- `app.js` — негізгі логика
- `tools.js` — есептегіштер және импорт
- `parse.js` — банк үзінділерін оқу (Kaspi, Freedom, Halyk, Forte…)
- `i18n.js` — орысша және ағылшынша аударма
- `sw.js` — офлайн кэш және еске салу хабарламалары
- `privacy.html` — құпиялылық саясаты
- `play/` — Google Play материалдары

Деректер тек құрылғыда сақталады (`localStorage` `qarzhy_v1` + IndexedDB `qarzhy`).
Ескі (v1) нұсқа git тарихында сақталған.
