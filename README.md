# Қаржы (Qarzhy)

Жеке қаржы қосымшасы. Толық офлайн жұмыс істейді, дерек тек құрылғыда сақталады.

**Сайт:** https://nn16nn.github.io/qarzhy/

---

## Файлдар

| Файл | Өлшемі | Не үшін |
|---|---|---|
| `index.html` | 68 КБ | Құрылым мен дизайн (HTML + CSS) |
| `app.js` | 239 КБ | Барлық логика — 5 000+ жол JavaScript |
| `sw.js` | 2 КБ | Офлайн кэш (қазір v6) |
| `manifest.webmanifest` | 1,5 КБ | PWA баптауы, жылдам жарлықтар |
| `icon-192.png` | 6 КБ | Кіші белгіше |
| `icon-512.png` | 18 КБ | Негізгі белгіше |
| `icon-maskable.png` | 15 КБ | Android кесетін белгіше |

Жетеуі де репозиторийдің **түбінде** тұруы керек, папкасыз.

---

## Қалай жаңарту

1. GitHub → `nn16nn/qarzhy`
2. **Add file → Upload files**
3. Өзгерген файлдарды тастаңыз
4. **Commit changes**
5. 1 минуттан кейін сайт жаңарады

Қосымшаны жабып, қайта ашыңыз. Баптау → Қосымша туралы бөлімінде нұсқа нөмірі көрінеді.

**Маңызды:** `index.html` мен `app.js` бірге жүреді. Біреуін ғана жүктесеңіз, қосымша жартылай ескі болып қалады — экран бос болуы немесе түймелер жұмыс істемеуі мүмкін.

Белгіше өзгерсе, қосымшаны басты экраннан өшіріп, сайтты Chrome-да ашып, қайта орнатыңыз — Android белгішені қатты кэштейді.

## Не бар

**Есеп**
- Кіріс-шығын, санаттар бойынша
- Шоттар: банк, қолма-қол, брокерлік, несие
- Шоттар арасында аударым (шығын болып есептелмейді)
- Таза капитал: банктегі ақша − міндеттемелер + қарыздар

**Инвестиция**
- Брокерлік шот жеке есептеледі
- Теңге мен доллар бөлек жүреді, бір-біріне аударылмайды
- Портфель құны қолмен қойылады, салынған қаражат жазбалардан есептеледі

**Қарыздар**
- Адамдарға берген және алған ақша
- Ішінара төлем, прогресс, мерзімі өткенде ескерту

**Импорт**
- Банк үзіндісі: PDF, Excel, CSV
- Freedom брокер есебі: клиент коды бойынша шотты өзі табады немесе құрады
- Қайталанған жазбаларды сүзеді

**Калькуляторлар**
- Несие: аннуитетті, дифференциалды, ерте өтеу
- Депозит: капитализация, толықтыру
- Инвестиция: күрделі пайыз
- Салық: ЖК оңайлатылған декларация

Әрқайсысынан PDF пен Excel шығады.

**Статистика**
- Дөңгелек диаграмма, санаттар үлесі
- 12 айлық интерактив график — нүктені бассаңыз сол айдың дерегі шығады
- PDF есеп және Excel экспорты

**Басқа**
- Үш тіл: қазақша, орысша, ағылшынша
- Ашық және қараңғы тақырып
- Күнделікті автокөшірме (7 күн сақталады)
- Жылдам жарлық: белгішені ұзақ басқанда

## Дерек қайда

**IndexedDB** — негізгі қойма, шегі жүздеген мегабайт.
**localStorage** — қосалқы көшірме.

Ешқандай серверге жіберілмейді. Баптау → Жад бөлімінде қанша орын алынғаны көрінеді.

Көшірме жасау: Баптау → **Деректі сақтау** — файл шығады, оны Google Drive-қа немесе поштаға сақтап қойыңыз.
