# Қаржы (Qarzhy)

Жеке қаржы қосымшасы. Толық офлайн жұмыс істейді, дерек тек құрылғыда сақталады.

**Сайт:** https://nn16nn.github.io/qarzhy/

---

## Файлдар

| Файл | Өлшемі | Не үшін |
|---|---|---|
| `index.html` | 68 КБ | Құрылым мен дизайн (HTML + CSS) |
| `app.js` | 239 КБ | Барлық логика — 5 000+ жол JavaScript |
| `sw.js` | 2 КБ | Офлайн кэш (қазір v57) |
| `manifest.webmanifest` | 1,5 КБ | PWA баптауы, жылдам жарлықтар |
| `fonts/` | 4 файл, 88 КБ | Onest шрифті (офлайн, қазақ әріптерімен) |
| `qlogo7-192.png` | 6 КБ | Кіші белгіше |
| `qlogo7-512.png` | 18 КБ | Негізгі белгіше |
| `qlogo7-maskable.png` | 15 КБ | Android кесетін белгіше |

Файлдар репозиторийдің **түбінде** тұрады; шрифттер `fonts/` папкасында.

## Қалай жаңарту

1. GitHub → `nn16nn/qarzhy`
2. **Add file → Upload files**
3. Өзгерген файлдарды тастаңыз
4. **Commit changes**
5. 1 минуттан кейін сайт жаңарады

Қосымшаны жабып, қайта ашыңыз. Баптау → Қосымша туралы бөлімінде нұсқа нөмірі көрінеді.

**Маңызды:** `index.html` мен `app.js` бірге жүреді. Біреуін ғана жүктесеңіз, қосымша жартылай ескі болып қалады — экран бос болуы немесе түймелер жұмыс істемеуі мүмкін.

Белгіше өзгерсе, қосымшаны басты экраннан өшіріп, сайтты Chrome-да ашып, қайта орнатыңыз — Android белгішені қатты кэштейді.

## Не бар

**Есеп**
- Кіріс-шығын, санаттар бойынша
- Шоттар: банк, қолма-қол, брокерлік, несие
- Шоттар арасында аударым (шығын болып есептелмейді)
- Таза капитал: банктегі ақша − міндеттемелер + қарыздар (мақсаттағы ақша капиталға кірмейді, бөлек көрсетіледі)
- Қайталанатын төлемдер: ай сайынғы төлем, мерзімі жақындағанда басты бетте ескерту, «Төледім» бір басу

**Ыңғайлылық**
- Санатты үйрену: бір дүкеннің санатын бір рет өзгертсеңіз, оның басқа «Басқа» операциялары мен келесі импорттары да сол санатқа түседі
- Операция қосқанда сома өрісі бірден ашылады, соңғы шот пен санат есте қалады
- Түсініктемеге бұрынғы жазбалардан ұсыныс шығады, таңдағанда санат өзі қойылады
- Басты беттегі Кіріс/Шығын картасын басса — сол түрдің статистикасы ашылады
- Күндік лимит: айлық шығын жоспарын қойсаңыз, басты бетте «Бүгін жұмсауға болады» шығады
- Болашақ (Статистика): ай соңына шығын болжамы, 6 және 12 айдан кейінгі капитал, мақсатқа қанша айда жететіні
- Төлем күнтізбесі (басты бет → Төлемдер күнтізбесі): тұрақты төлемдер, несие (төлем күні шот баптауында), қарыздар бір айлық күнтізбеде
- Жылдық есеп (Статистика): жыл кірісі, шығыны, ең үнемді/шығынды ай, ең көп санат пен дүкен
- Байқағандарым (басты бет): санат шығыны өткен аймен салыстырғанда күрт өссе/азайса, ставкаға айлық шығын
- Несие өтеу жоспары (несие шотын ашқанда): айына қосымша төлем → неше ай ерте жабылады, қанша пайыз үнемделеді
- Зейнетақы (ЕНПФ) — бөлек бет (Басты → Зейнетақы, не Шоттар → Зейнетақы). ЕНПФ үзіндісін (PDF) жүктесеңіз, өзі оқиды: шоттар (ОПВ · Ұлттық банк, ОПВ · ИПБ, ОПВР), барлық түсімдер, жұмыс берушілер, инвестициялық табыс, табыстылық пен инфляция кестесі, жеткіліктілік шегі мен ЕПВ сомасы
- Есептейді: айына орташа жарна (12 ай), айына инвестициялық табыс, келесі ай / 1 жыл / 5 жылға болжам, шекке жететін жыл, 63 жасқа (бүгінгі ақшамен). Болжам жылдардың орташа табыстылығымен. Таза капиталға қосылмайды. Шектерді жыл сайын жаңарту керек (ENPF_MIN)
- Жалпы «Файл жүктеу» арқылы ЕНПФ үзіндісін берсеңіз де, Зейнетақы бетіне түседі
- Айлық қорытынды: Статистика → Ай бетінде әр айдың кірісі, шығыны, нәтижесі, ең көп санаттары; айдың алғашқы 10 күнінде басты бетте де шығады
- Тұрақты төлемдерді табу: ай сайын қайталанатын төлемдер (Netflix, т.б.) «Қайталанатын төлемдер» бетінде ұсынылады
- Топтап санат өзгерту: Операциялар → «Таңдау · Санат» → белгілеу → Санат
- Чектен қосу: операция терезесінде «Чектен» — суреттегі чектен сома, күн, дүкен оқылады (бірінші рет интернет керек)
- Kaspi Gold PDF үзіндісі (қазақша және орысша): барлық операция түрлері, ескі жазбаларды ауыстыру, қалдықты банкпен теңестіру

**Инвестиция**
- Брокерлік шот жеке есептеледі
- Теңге мен доллар бөлек жүреді, бір-біріне аударылмайды
- Портфель құны қолмен қойылады, салынған қаражат жазбалардан есептеледі

**Қарыздар**
- Адамдарға берген және алған ақша
- Ішінара төлем, прогресс, мерзімі өткенде ескерту

**Импорт**
- Банк үзіндісі: PDF, Excel, CSV
- Freedom Bank (Super Card) PDF үзіндісі: арнайы оқылады — «5,100.00» пішіміндегі сомалар, бөлек жолға түскен сомалар, USD/EUR жолдары (қосылмайды), банк растамаған операциялар (белгісіз қалады). Бұрынғы қате импортты ауыстыру және шот қалдығын банктегімен теңестіру мүмкіндігі бар
- Freedom брокер есебі: клиент коды бойынша шотты өзі табады немесе құрады
- Кэшбэк жолдары кіріс болып, «Кэшбэк» санатына түседі; сатып алу жолындағы кэшбэк сомасы шығынға қосылмайды
- Қайталанған жазбаларды сүзеді

**Калькуляторлар**
- Жалақы бөлу: айлықты пайызбен бөліп, жоспарды сақтап қояды. Әр бөлімді мақсатқа, инвестицияға немесе басқа шотқа байлап, «Жоспарды орындау» басуға болады
- Несие: аннуитетті, дифференциалды, ерте өтеу
- Депозит: капитализация, толықтыру
- Инвестиция: күрделі пайыз
- Салық: ЖК оңайлатылған декларация

Әрқайсысынан PDF пен Excel шығады.

**Статистика**
- Кэшбэк қорытындысы: осы ай, өткен ай, шығынның қанша пайызы қайтты
- Дөңгелек диаграмма, санаттар үлесі
- 12 айлық интерактив график — нүктені бассаңыз сол айдың дерегі шығады
- PDF есеп және Excel экспорты

**Басқа**
- Үш тіл: қазақша, орысша, ағылшынша
- Ашық және қараңғы тақырып
- Күнделікті автокөшірме (7 күн сақталады)
- Жылдам жарлық: белгішені ұзақ басқанда

## Дизайн

Qarzhy бренді (әдепкі стиль): қою көк (`#141B2D`) және маржан-қызыл (`#F0453A`). Логотип — көзді көк 3D Q (`qlogo7-*.png`, иесі берген сурет).

- Ашылу экраны: қою көк фон, маржан жарық, ақ логотип
- Баланс картасы мен бірінші мақсат — қою көк, график қызыл
- Негізгі түймелер («+», Кіріс қосу, Сақтау) — маржан градиент
- Фон: әр стильдің түсіндегі бұлыңғыр түрлі түсті дақтар, баяу қозғалады, карталар жартылай мөлдір
- Басты бетте шот карталары: баланс картасын солға сырғытса, әр банк өз түсіндегі карта болып шығады
- Шығын сомасы бейтарап қою түспен, қызыл тек түймелерде
- Ашық және қараңғы тақырып; стильдер (Профиль → Дизайн стилі): Qarzhy, Классик, Изумруд, Күлгін, Мұхит, Күн батуы, Раушан

Шрифт: **Onest** (қосымшаның өзінде, интернет керек емес).
